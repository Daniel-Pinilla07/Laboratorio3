Laboratorio 3 — React Hooks (useEffect) abriendo API

Universidad Libre — Facultad de Ingeniería Programación Web · Semestre VI · 2026-II

Descripción del proyecto

Aplicación web desarrollada en React que utiliza el Hook useEffect para consumir la API pública Fake Store API y mostrar un catálogo de productos con su nombre, descripción, imagen y precio. El maquetado se realizó con Bootstrap y una hoja de estilos propia (styles.css) para complementar el diseño.

Tecnologías utilizadas
React (Hook useEffect + useState)
Fetch API / async-await para el consumo del servicio
Bootstrap (estructura y componentes visuales)
CSS propio (styles.css)
GitHub / GitHub Codespaces
